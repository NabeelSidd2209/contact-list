📱 Contact Management System

A simple Contact Management System built using Python.
This project allows users to add, delete, edit, search, and display contacts through a menu-driven console application.

🚀 Features
    🔐 Username and password authentication
    ➕ Add new contacts
    🗑️ Delete existing contacts
    ✏️ Edit contact information
    🔍 Search contacts
    📋 Display all saved contacts
    🚪 Exit the application
    💾 Stores contact information using a Python dictionary
